# BookLabel - 图书数据加工与标注平台

基于 Vue 3 + Tailwind CSS 的单文件 HTML 应用，用于图书数据的逐页标注、知识抽取与数据集生成。

## 功能

- 📚 **书单管理** — 多本图书列表，点击进入逐页标注
- 📖 **逐页翻阅** — 上一页/下一页翻页导航 + 快速跳页
- 📋 **图书信息** — 元数据录入（ISBN/分类/版权/数据等级等）
- 📖 **结构校准** — AI 解析 + 人工校准段落结构
- 🏷️ **知识标注** — NER 实体识别、知识点标注、关系三元组
- 🔍 **质量审核** — 内容安全审核 + AI 审核建议
- 📦 **数据集导出** — 多格式导出（JSON/JSONL/QA/CSV/PDF）
- 📐 **自定义维度** — 灵活扩展标注维度

## 当前数据

- 《活着》余华 — 62 页正文内容（PDF 第 4-65 页）

## 部署

纯静态页面，直接用 GitHub Pages 或任意静态服务器部署即可。

## 技术栈

- Vue 3 (CDN)
- Tailwind CSS (CDN)
- 无需构建，单 HTML 文件 + 外部数据 JS
